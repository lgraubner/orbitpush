Yes. It is also a good smoke test for the fastest OrbitPush path: upload one HTML file and get a live URL quickly.

What should fail here?

Not much. If this breaks, the most basic upload and publish path is not healthy.

What is intentionally missing?

No images, no external CSS, no nested pages, and no build step.
